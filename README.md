# MskProd Computing

A free computing revision website for UK students at Key Stage 3, GCSE and A Level,
served at **https://mskprod.org**.

Written to the OCR specifications, with a full explanation, key terms, flashcards,
a ten question knowledge check and five auto marked exam-style questions for every
topic, plus original full length practice papers with mark schemes.

No accounts, no cookies, no adverts, no tracking.

## Building the site

The site is static HTML generated by a single Python script with no third party
dependencies.

```bash
python3 build.py
```

This writes the complete site into `dist/`, including `sitemap.xml`, `robots.txt`,
`search-index.json`, `site.webmanifest`, a `404.html` and the `CNAME` file.

To preview it locally:

```bash
python3 build.py && python3 -m http.server 8000 --directory dist
```

Then open http://localhost:8000

## Adding a topic

Every topic is a `Topic` object. Add one to the relevant list in `content/`, then
rebuild. The build script picks it up automatically and adds it to the navigation,
the sitemap and the search index.

```python
Topic(
    slug="my-topic",
    title="My Topic",
    spec="1.2.3",
    icon="i-cpu",
    blurb="One sentence describing it.",
    sections=[Section("Heading", """Mini markup content""")],
    keyterms=[("Term", "Definition")],
    grade="""What separates a top grade answer.""",
    mistakes=["Something students actually get wrong."],
    quiz=[Q("Question?", ["A", "B", "C", "D"], 0, "Why A is right.")],
    exam=[EQ("Explain something.", 3, [MP("Point", ["keyword"])], "Model answer.")],
)
```

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds the site and
publishes `dist/` to GitHub Pages.

### One off setup

1. In the repository, go to **Settings → Pages** and set **Source** to
   **GitHub Actions**.
2. Still under **Settings → Pages**, set the **Custom domain** to `mskprod.org`
   and tick **Enforce HTTPS** once the certificate has been issued.
3. Add the DNS records below at your registrar.

### DNS records for mskprod.org

The domain is registered through Squarespace, which took over Google Domains.
Squarespace's own website builder cannot host this site, but the domain can point
anywhere, so keep the domain where it is and add these records in
**Squarespace → Domains → mskprod.org → DNS Settings**.

For the apex domain, add four **A** records, all with host `@`:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

Optionally add the matching **AAAA** records for IPv6, also with host `@`:

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

For the `www` subdomain, add one **CNAME** record:

```
Host:  www
Value: <your-github-username>.github.io
```

Remove any existing Squarespace parking or forwarding records for `@` and `www`
first, or they will conflict. DNS changes usually take effect within an hour but
can take up to 48 hours to propagate fully.
